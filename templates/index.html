MedCheck: A machine-learning model demo

MedCheck is an educational portfolio project that brings together seven machine-learning model demos in a Flask web app. Depending on the demo, users enter selected health measurements or upload a medical image.

About the project

The project demonstrates a simple end-to-end workflow: a user submits data through a web form, Flask passes it to a trained model, and the app displays the model's output. The project includes both tabular-data models and image-classification models.

Important note

MedCheck is an educational demonstration, not a medical device. Its results are not a diagnosis and should not be used to make healthcare decisions. Please speak with a qualified healthcare professional about medical concerns.
